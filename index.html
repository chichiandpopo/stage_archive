HOW TO USE

공통 사용법

1바로가기(홈 화면 아이콘) 만들기

  1. 아이폰(Safari) — 티켓을 눌러 사이트 접속 → 하단 공유 버튼(⬆) → "홈 화면에 추가" → 이름 확인 후 추가
  2. 안드로이드(Chrome) — 사이트 접속 → 오른쪽 위 점 3개(⋮) 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
  3. PC(Chrome/Edge) — 주소창 오른쪽 설치 아이콘 클릭, 없으면 메뉴(⋮) → "앱 설치"
⚠️ 아이폰은 꼭 Safari로 접속해서 추가해야 "홈 화면에 추가" 메뉴가 보여요. 7개 사이트를 다 쓰신다면 이 페이지 자체를 먼저 홈 화면에 추가해두고, 여기서 각 티켓으로 이동하는 것도 방법이에요.

2화면 구성

  • 출연 일정 표 — 날짜·요일·시간·배역별 배우·좌석·복사(🎤) 버튼으로 전체 회차를 보여줘요
  • 배우 필터 — 배역별 배우 이름을 눌러 원하는 조합만 골라볼 수 있어요 (여러 명 동시 선택 가능)
  • 📌 필터 고정 — 필터를 선택한 뒤 "고정하기"를 누르면 다음 방문 때도 그 조합이 자동 유지돼요
  • 좌석 입력 — 실제 관람한 회차의 좌석을 예시 형식으로 입력해두면, 그게 "내가 본 회차" 기록의 기준이 돼요
  • 캐스팅 복사 — 회차별 아이콘으로 날짜·배우 정보를 텍스트로 복사해 공유할 수 있어요
  • 정산(집계) — 배우별로 "내가 좌석을 입력한 횟수 / 필터된 전체 회차 수"를 카드로 보여줘요
  • 좌석 배치도 — 입력한 좌석이 극장 지도 위에 표시되고, 같은 자리에 여러 번 앉았다면 색이 진해져요
  • 💾 데이터 저장/불러오기 — 기록을 JSON 파일로 내려받아 백업하고, 다른 기기에서 불러와 복원할 수 있어요

3알아두면 좋은 점

  • 로그인이 필요 없고, 기록은 내 브라우저(localStorage)에만 저장돼요 — 서버로 전송되지 않아요
  • 7개 사이트는 주소가 각각 달라서 기록도 사이트별로 따로 저장돼요. 공연마다 "내 데이터 저장"으로 각자 백업해두세요
  • 브라우저 캐시를 지우거나 기기를 바꾸면 기록이 사라질 수 있으니, 종종 백업 파일을 받아두는 걸 추천해요
  • 비공식 스케줄 정리 사이트입니다. 실제 캐스팅은 예매처·제작사 공지로 최종 확인해주세요
